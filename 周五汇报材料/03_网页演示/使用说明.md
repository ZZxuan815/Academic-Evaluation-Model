# 知行学业成长评估原型

双击 index.html，用 Edge 或 Chrome 打开即可，不需要安装依赖或联网。

演示：点击载入示例 → 修改问卷数据 → 推荐并人工增删指标 → 比较等权与短板关注变权 → 生成报告 → 导出 JSON。

成绩、出勤除以100；学习时长按4小时封顶映射；实践按5次封顶；睡眠按距离8小时的偏差映射。这些均为人工设定的演示规则，不能作为经过验证的评价标准。日均睡眠不能推断作息规律。成绩变化不能推断群体进步位次。

目前未接入真实数据集、群体标准化、机器学习筛选和后端。数据只在当前页面内使用，刷新后恢复示例。雷达图少于三个所选指标时展示全部背景指标，并明确说明。

## v0.2 新增功能

首页可切换持续进步、均衡发展、状态回落三种模拟案例，自动生成综合发展报告。侧栏可跳转各流程区域；指标说明可展开查看；报告同时展示同一指标集合下的等权和变权评分，并优先推荐两项行动。修改输入后旧报告隐藏，需要重新生成。

验证：node verify.cjs 检查核心计算和边界输入；node --check enhance.js 检查新增脚本语法。浏览器实际渲染和点击流程尚未完成验证。
