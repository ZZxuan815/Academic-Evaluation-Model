# 本地千问平台

在平台目录运行 powershell -File 启动本地平台.ps1，再用浏览器访问 http://127.0.0.1:8787 。不要通过双击HTML使用模型按钮；规则模式仍可单独打开。

模型：Ollama qwen3:4b，模型文件保存在项目.runtime/models，运行工具在.runtime/ollama。使用前需下载完成。

当前支持：真实模型后端接口、规则模式、指标确认、评估报告、三项行动积分、首次完成与累计五项徽章。积分保存在当前浏览器，支持取消勾选撤销。该轻量模块为项目自行实现，尚未集成GamificationKit；已加入本周行动天数与3天达成提示。

公开上线仍待完成。127.0.0.1是本机地址，不能作为发给答辩观众的网络链接。模型端口没有公开到网络。
