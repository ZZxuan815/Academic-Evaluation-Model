# 账号与历史记录

打开 http://127.0.0.1:8787/ 并刷新页面，在“我的成长档案”填写用户名和至少8位密码，选择注册并登录。随后生成成长报告会自动保存，未登录时会提示先登录；登录后可点击报告下方“保存本次评估”补存。

历史区按同一组指标、等权/变权方案、变权强度及公式版本分组。选择比较口径后可查看分数曲线、时间、分数以及和上次的差值。折线横轴为记录顺序，不表示等间隔日期。同一份报告重复点保存不会新增；重新生成报告会视为新一次评估，即使数据相同。示例按钮本身不会自动保存，手动保存前应核对是否为真实数据。

记录使用服务器生成的时间，分数由后端重新计算。用户只能读取自己的历史。密码使用随机盐和 scrypt 哈希，登录使用 HttpOnly、SameSite Cookie，有效期七天。账号、会话和评估存放在 server/private/accounts.sqlite，数据库未开放为静态网页，已设置目录忽略规则。数据库包含个人评估数据，备份时应妥善保存整个 private 目录，备份前停止平台。

当前是本机版本，账号不自动同步到其他服务器。尚无找回密码功能。部署到公网前需配置 HTTPS 和 Secure Cookie，并完善账号恢复、存储备份及运行环境；当前服务只监听本机地址。

验证：HTTP 集成测试覆盖注册、错误密码、登录态读取、退出失效、跨账号隔离、重复提交、服务重建后的持久化、请求来源校验、异常输入拒绝、服务端分数重算。现有评分逻辑回归测试通过。浏览器视觉与实际点击流程尚未完成验证。
